# TV UX PRINCIPLES

1. TV First.
Never build for mouse-first interaction.

2. Content First.
Users should browse content, not providers.

3. Configure Once.
Provider keys, IPTV, playback preferences and region are configured once.

4. Watch Immediately.
The app should require the fewest possible interactions before playback.

5. Clean Home.
The home screen is curated, not a database.

6. No Browser Feel.
No browser scrollbars, browser focus or web-like navigation.

7. Consistency.
Every screen follows identical navigation rules.

8. Simplicity.
Every feature must reduce friction instead of adding it.

9. Premium Experience.
Every interaction should feel comparable to commercial OTT TV apps.

10. Performance First.
Fast startup, smooth scrolling and responsive remote navigation are mandatory.
